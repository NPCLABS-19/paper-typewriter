# Paper

A red manual typewriter on a walnut desk, with a readable centered sheet, dark ribbon ink, and recorded keys, bell, and carriage return. The metal head strikes each letter and moves across the sheet. Enter sweeps the head back and feeds the paper one line.

## Use
Just type. Enter returns the carriage. Backspace and Delete both erase the last character. From an empty line they go back to the previous line. Use Fresh sheet in the menu to tear away the current sheet and start another. Automatic correction, capitalization, and spellcheck are disabled. On a phone, tap the paper to open the keyboard.

Escape or the lower-right menu opens text/PNG download, print/PDF, sound and volume, fullscreen, fresh sheets, and the local sheet archive. Cmd/Ctrl+S saves plain text. Long lines wrap visually to fit the sheet. Scroll or swipe vertically to review earlier lines. Typing returns to the writing point. Your ten most recent pages are preserved locally.

Documents autosave to localStorage in the current browser. Export copies for use elsewhere; clearing browser data clears local sheets. No backend, account, analytics, or tracking.

## Develop
`npm install`, then `npm run dev` (http://127.0.0.1:4400). Production is the same buildless HTML/CSS/JS, with self-hosted assets. `npm test` runs model and browser behavior checks. See CREDITS.md for sample and font licenses.
